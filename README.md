# 🎮 Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**. Play against the computer and track your score in real-time!

---

## 📸 Preview

![Game Preview](./imag/game-preview.png)

---

## 🚀 Features

- 🧠 Computer generates random moves  
- 👆 Click-based user interaction  
- 📊 Live score tracking (Player vs Computer)  
- 🎨 Clean and responsive UI  
- ⚡ Instant result display (Win / Lose / Draw)

---

## 🛠️ Tech Stack

- HTML5 – Structure of the game  
- CSS3 – Styling and layout  
- JavaScript (ES6) – Game logic and interactivity

## 🎯 How to Play

1. Click on Rock, Paper, or Scissors  
2. The computer randomly selects its move  
3. The result is displayed instantly:
   - Rock beats Scissors  
   - Paper beats Rock  
   - Scissors beats Paper  
4. Scores update automatically on the screen  

---

## ▶️ Run Locally

1. Clone the repository  
   git clone https://github.com/your-username/rock-paper-scissors.git

## 💡 Game Logic

- Computer choice is generated randomly using JavaScript  
- Game conditions determine win, lose, or draw  
- Scores and messages are updated dynamically on the UI
